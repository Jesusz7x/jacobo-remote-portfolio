PROJECT 01 · PYTHON · DATA QUALITY

CSV Data Cleaner

A small command-line tool for reviewing and cleaning tabular CSV files while keeping the original safe.

Problem and audience

Small teams often receive CSV exports with inconsistent whitespace, blank fields, or repeated records. This tool provides a reproducible first-pass quality summary for an operator before further analysis.

Features

  • Reads UTF-8 with BOM and common Windows encodings.
  • Counts blank values by column and surrounding whitespace.
  • Removes exact duplicate rows and trims values into an explicitly named output.
  • Writes an optional JSON report and rejects malformed rows or unsafe output paths.

Run and verify

python3 projects/01-data-cleaner/clean_csv.py projects/01-data-cleaner/sample.csv --output /tmp/cleaned.csv --report /tmp/quality.json
python3 -m unittest discover -s tests -v

Sample data is synthetic. The original file is never modified. No third-party dependencies are required.

Limitations

Email syntax, required fields, numeric values, ISO dates, and possible numeric outliers can be checked through an optional JSON schema. Outliers are warnings only; they are not removed. Identifiers and domain rules still need custom logic. Review the output, and note that CSV cannot preserve rich spreadsheet formatting.

Code: projects/01-data-cleaner/clean_csv.py in the local workspace. No public source repository or hosted demo is configured.

PROYECTO 01 · PYTHON · CALIDAD DE DATOS

Limpiador de CSV

Una herramienta pequeña de línea de comandos para revisar y limpiar archivos CSV tabulares, preservando el original.

Problema y público

Los equipos pequeños suelen recibir exportaciones CSV con espacios inconsistentes, campos vacíos o registros repetidos. Esta herramienta genera un resumen reproducible de calidad antes de continuar el análisis.

Funciones

  • Lee UTF-8 con BOM y codificaciones comunes de Windows.
  • Cuenta valores vacíos por columna y espacios sobrantes.
  • Quita duplicados exactos y espacios en una salida con ruta explícita.
  • Genera un informe JSON opcional y rechaza filas malformadas o rutas de salida inseguras.

Ejecución y verificación

python3 projects/01-data-cleaner/clean_csv.py projects/01-data-cleaner/sample.csv --output /tmp/limpio.csv --report /tmp/calidad.json
python3 -m unittest discover -s tests -v

Los datos de muestra son sintéticos. El original nunca se modifica. No se requieren dependencias externas.

Limitaciones

Con un esquema JSON opcional, se puede validar sintaxis de correo, campos obligatorios, números, fechas ISO y posibles valores atípicos. Estos últimos solo se señalan y no se eliminan. Los identificadores y reglas de dominio aún requieren lógica propia. Revisa los resultados; CSV no conserva el formato complejo de una hoja de cálculo.

Código: projects/01-data-cleaner/clean_csv.py en el espacio local. No hay repositorio público ni demostración alojada configurados.
