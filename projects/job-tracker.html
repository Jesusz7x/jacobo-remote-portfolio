PROJECT 02 · PYTHON · SQLITE

Job Application Tracker

A local-first command-line tool for organizing job listings and candidacies without sharing data with a service.

Problem and audience

Job searches create many links, eligibility checks, follow-ups, and status changes. The tracker keeps these records in a local SQLite file and distinguishes discovered opportunities from applications actually submitted.

Features

  • Create, search, filter, and update opportunity status.
  • Record location eligibility, pay basis, requirements, and follow-up dates.
  • Import and export CSV with basic validation.
  • Aggregate records by status; no passwords or automatic application submission.

Run and verify

python3 tools/job_tracker/tracker.py add --company "Example" --role "Junior QA" --eligible-countries "El Salvador" --status "To review"
python3 tools/job_tracker/tracker.py list --stats
python3 -m unittest discover -s tests -v

The default database is in ignored data/applications.sqlite3. Set --db to use another path.

Limitations

This is a local single-user CLI, not a hosted application. It does not verify job listings, country eligibility, salaries, or whether an application was actually sent. Record these facts only after checking the original source.

Code: tools/job_tracker/tracker.py in the local workspace. No public source repository or hosted demo is configured.

PROYECTO 02 · PYTHON · SQLITE

Seguimiento de candidaturas

Una herramienta local de línea de comandos para organizar vacantes y candidaturas sin compartir datos con un servicio externo.

Problema y público

La búsqueda de empleo acumula enlaces, verificaciones de elegibilidad, seguimientos y cambios de estado. La herramienta guarda los registros en SQLite local y diferencia una vacante encontrada de una candidatura realmente enviada.

Funciones

  • Crear, buscar, filtrar y actualizar estados de vacantes.
  • Registrar países permitidos, base salarial, requisitos y fechas de seguimiento.
  • Importar y exportar CSV con validaciones básicas.
  • Resumir registros por estado; no almacena contraseñas ni envía candidaturas automáticamente.

Ejecución y verificación

python3 tools/job_tracker/tracker.py add --company "Ejemplo" --role "QA Junior" --eligible-countries "El Salvador" --status "To review"
python3 tools/job_tracker/tracker.py list --stats
python3 -m unittest discover -s tests -v

La base de datos predeterminada está en data/applications.sqlite3, excluida de Git. Usa --db para indicar otra ruta.

Limitaciones

Es una CLI local para una sola persona, no una aplicación alojada. No verifica ofertas, elegibilidad por país, salarios ni si una candidatura se envió. Comprueba esos datos en la fuente original antes de registrarlos.

Código: tools/job_tracker/tracker.py en el espacio local. No hay repositorio público ni demostración alojada configurados.
