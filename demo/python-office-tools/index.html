Try three browser adaptations of tools from the Python repository: clean a CSV, compare two lists, or track sample applications. Files stay on your device.

Honest scopeThese are client-side adaptations, not the original Python CLI or a hosted processing service. No selected file is uploaded.

01 / DATA QUALITY

Clean a CSV

Preview trimmed values, missing cells and exact duplicate rows before downloading.

02 / RECORD RECONCILIATION

Compare two CSV lists

Match a unique key and inspect changed fields plus records found on only one side.

03 / PERSONAL WORKFLOW

Track sample applications

A small local tracker inspired by the repository's SQLite and CSV utility.

Use fictional records only. Entries stay in this browser tab and clear when it closes. Never enter private contact details.

IMPLEMENTATION NOTES

Local processing

CSV files are read with the browser File API and parsed in memory. Download links are generated locally; nothing is sent to a server.

Source repository

The original Python tools use the standard library: csv, pathlib, hashlib and SQLite. They preserve source files and preview risky operations.

What's different

This demo does not organize or rename real folders, and the tracker is not the Python SQLite database. The web adaptation is intentionally isolated.
